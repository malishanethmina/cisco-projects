# Project 1 — Multi-Department Office Network

## Overview
A multi-department office network designed and configured using Cisco Packet Tracer.

## Departments
- Admin
- IT
- Sales
- Server

## Technologies & Concepts
- IPv4 Addressing
- Subnet Masks
- VLANs
- 802.1Q Trunking
- Router-on-a-Stick
- Inter-VLAN Routing
- DHCP
- ARP
- MAC Address Learning
- ICMP / Ping
- Basic Network Troubleshooting

## VLANs

| VLAN | Department | Network | Gateway |
|---|---|---|---|
| 10 | ADMIN | 192.168.10.0/24 | 192.168.10.1 |
| 20 | IT | 192.168.20.0/24 | 192.168.20.1 |
| 30 | SALES | 192.168.30.0/24 | 192.168.30.1 |
| 40 | SERVER | 192.168.40.0/24 | 192.168.40.1 |

## Devices
- 1 Router
- 1 Switch
- 6 PCs
- 1 Server

## Verification
- VLAN configuration verified
- 802.1Q trunk verified
- DHCP leases verified
- ARP table verified
- Switch MAC address table verified
- Inter-VLAN connectivity tested successfully
